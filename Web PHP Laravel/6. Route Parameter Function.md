# 🔀 Route Parameter Function in Controller

ផ្នែកនេះពន្យល់អំពីការបញ្ជូន ទិន្នន័យតាម **Route Parameters** (`empid`, `empname`, `position`) ទៅកាន់ **Controller Method** និងបង្ហាញលទ្ធផលនៅលើ **View**។

### 🔄 លំហូរការងារ (Data Flow):

```text
Employee 1 (Click Link)
          ↓
Route with Parameters (/employee/detail/101/John/Manager)
          ↓
EmployeeController@detail
          ↓
resources/views/employee/detail.blade.php
          ↓
Display:
  - Employee ID: 101
  - Name: John
  - Position: Manager
```

---

## 📌 Step 24 — EmployeeController

**ទីតាំងឯកសារ:** `app/Http/Controllers/EmployeeController.php`

```php
<?php

namespace App\Http\Controllers;

class EmployeeController extends Controller
{
    public function home()
    {
        return view('home');
    }

    public function detail($empid, $empname, $position)
    {
        return view('employee.detail', [
            'empid' => $empid,
            'empname' => $empname,
            'position' => $position
        ]);
    }
}
```

> **ចំណាំ:** Method `detail()` ទទួល 3 Parameters (`$empid`, `$empname`, `$position`) ហើយបញ្ជូនបន្តទៅ View តាមរយៈ Array។

---

## 📌 Step 25 — Employee Routes

**ទីតាំងឯកសារ:** `routes/web.php`

ធ្វើការ Import Controller និងកំណត់ Named Routes:

```php
use App\Http\Controllers\EmployeeController;

Route::get('/employee', [EmployeeController::class, 'home'])
    ->name('employee.home');

Route::get(
    '/employee/detail/{empid}/{empname}/{position}',
    [EmployeeController::class, 'detail']
)->name('employee.detail');
```

> **ចំណាំ:** Laravel បញ្ជូនតម្លៃពី URL Parameters (`{empid}`, `{empname}`, `{position}`) ចូលទៅ Parameter របស់ Controller Method ដោយស្វ័យប្រវត្តិ។
