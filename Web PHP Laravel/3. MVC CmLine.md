# 🛠️ Command Line to Make MVC Components in Laravel

ឯកសារនេះពន្យល់អំពីការប្រើប្រាស់ Artisan Commands ដើម្បីបង្កើត **Controllers**, **Models**, **Migrations** និងការរៀបចំរចនាសម្ព័ន្ធ **Views** តាមគំរូ MVC Pattern។

---

## 📌 Step 7 — Create Controllers

បង្កើត Controllers ទាំង ៥ តាម Assignment តម្រូវ៖
- `StudentController`
- `TeacherController`
- `ProductController`
- `CategoryController`
- `EmployeeController`

### 7.1 រត់ Command ខាងក្រោមម្តងមួយៗ (Run Commands):
```bash
php artisan make:controller StudentController
php artisan make:controller TeacherController
php artisan make:controller ProductController
php artisan make:controller CategoryController
php artisan make:controller EmployeeController
```

### 7.2 ទីតាំង និងលទ្ធផល (Location & Result):
Controllers ទាំងអស់ត្រូវបាញ់ចូលទៅកាន់ទីតាំង: `app/Http/Controllers/`

```text
app/Http/Controllers/
├── StudentController.php
├── TeacherController.php
├── ProductController.php
├── CategoryController.php
└── EmployeeController.php
```

---

## 📌 Step 8 — Create Models + Migrations

ប្រើប្រាស់ Flag `-m` ជាមួយ Command បង្កើត Model ដើម្បីបង្កើត **Migration** ក្នុងពេលតែមួយ (`-m = create Migration together with Model`)។

### 8.1 រត់ Command (Run Commands):
```bash
php artisan make:model Student -m
php artisan make:model Teacher -m
php artisan make:model Product -m
php artisan make:model Category -m
php artisan make:model Employee -m
```

> **ចំណាំ:** យោងតាម Laravel Official Documentation គឺប្រើ `php artisan make:model ModelName` សម្រាប់បង្កើត Eloquent Model។

### 8.2 ទីតាំង និងលទ្ធផល (Location & Result):
Models ទាំងអស់ត្រូវបានរក្សាទុកក្នុងទីតាំង: `app/Models/`

```text
app/
└── Models/
    ├── Student.php
    ├── Teacher.php
    ├── Product.php
    ├── Category.php
    └── Employee.php
```

---

## 📌 Step 10 — Create Views Folder Structure

រៀបចំរចនាសម្ព័ន្ធ Folder និង Blade Views នៅក្នុងទីតាំង: `resources/views/`

### 10.1 រចនាសម្ព័ន្ធ (Folder & File Structure):
```text
resources/
└── views/
    ├── home.blade.php
    ├── index.blade.php
    │
    ├── student/
    │   ├── liststudent.blade.php
    │   └── addstudent.blade.php
    │
    ├── product/
    │   ├── listproduct.blade.php
    │   └── addproduct.blade.php
    │
    ├── category/
    │   ├── listcategory.blade.php
    │   └── addcategory.blade.php
    │
    └── employee/
        ├── create.blade.php
        ├── detail.blade.php
        ├── edit.blade.php
        └── delete.blade.php
```
