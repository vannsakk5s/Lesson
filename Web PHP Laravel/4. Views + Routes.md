ឯកសារនេះណែនាំអំពីការបង្កើត **Blade Views** និងការកំណត់ **Routes** សម្រាប់ផ្នែក **Product** (ផ្នែកទី III) និង **Category** (ផ្នែកទី VI) ក្នុង Assignment។

## 📌 Step 13 — Add Product Routes

បើកឯកសារ **`routes/web.php`** ហើយបន្ថែម Routes ដូចខាងក្រោម៖

```php
<?php

use Illuminate\Support\Facades\Route;

Route::get('/product/listproduct', function () {
    return view('product.listproduct');
});

Route::get('/product/addproduct', function () {
    return view('product.addproduct');
});
```

💡 **ជម្រើសសរសេរខ្លី (Shorthand Syntax):**
```php
Route::view('/product/listproduct', 'product.listproduct');
Route::view('/product/addproduct', 'product.addproduct');
```

---

## 📌 Step 14 — Test Product

សាកល្បងនៅលើ Browser:
1. `http://127.0.0.1:8000/product/listproduct` 
   - **Output:** `Welcome to List Product Form`
2. `http://127.0.0.1:8000/product/addproduct`
   - **Output:** `Add Product Information`

> **✅ Product complete.**
