# 🔄 Route → Controller Function → View 

មេរៀននេះពន្យល់អំពីលំហូរការងារ (Workflow Flowchart) នៃ Laravel Web Application ក្នុងការភ្ជាប់ **Route**, **Controller**, និង **View**:

```text
URL (Request)
    ↓
  Route
    ↓
Controller Function
    ↓
  View
    ↓
Browser (Response)
```

**ឧទាហរណ៍ជាក់ស្តែង (Example):**
```text
/student/info/allstudent
           ↓
StudentController@show
           ↓
student/liststudent.blade.php
```

## 📌 Step 21 — StudentController

**ទីតាំងឯកសារ:** `app/Http/Controllers/StudentController.php`

```php
<?php

namespace App\Http\Controllers;

class StudentController extends Controller
{
    public function show()
    {
        return view('student.liststudent');
    }

    public function create()
    {
        return view('student.addstudent');
    }
}
```

---

## 📌 Step 22 — Import StudentController & Define Routes

បើកឯកសារ **`routes/web.php`** រួចធ្វើការ Import Controller និងបន្ថែម Routes ដូចខាងក្រោម៖

```php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\StudentController;

Route::get('/student/info/allstudent', [StudentController::class, 'show']);
Route::get('/student/create', [StudentController::class, 'create']);
```

> **💡 ស្តង់ដារ Laravel Controller Route:**
> ```php
> Route::get('/user/{id}', [UserController::class, 'show']);
> ```
> Route នឹងហៅទៅកាន់ `public method` ជាក់លាក់មួយដែលនៅក្នុង Controller។
