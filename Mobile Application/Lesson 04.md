### មេរៀនទី៤ Collections

**១. គោលបំណងនៃមេរៀន**

នៅក្នុងមេរៀនមុនៗ យើងបានប្រើប្រាស់ប្រភេទទិន្នន័យមួយចំនួនរួចមកហើយ ដូចជា: តួអក្សរ ចំនួនគត់ ចំនួនទសភាគជាដើម។ ទោះជាប្រភេទទិន្នន័យទាំងនោះមានសារៈប្រយោជន៍ យ៉ាងណាក្តី ប៉ុន្តែការងារមួយចំនួន មិនអាចប្រើប្រភេទទិន្នន័យទាំងនេះមកអនុវត្តការងារ ដោយងាយនោះទេ តួយ៉ាងក្នុងមេរៀននេះអ្នកនឹងបានយល់ពីប្រភេទទិន្នន័យ ដែលអាចរក្សាទុកធាតុច្រើនក្នុងអថេរតែមួយ ។

នៅក្នុងមេរៀននេះ នឹងបង្ហាញអោយអ្នកមានសមត្ថភាពដូចខាងក្រោម:
- ស្វែងយល់ពីប្រភេទនៃ Collections
- ការប្រើប្រាស់ List, Set, Map
- ការប្រើប្រាស់ Method របស់ Collections
- យល់ដឹងពី អត្ថប្រយោជន៍របស់ Collections

**២. List**

List គឺជាបណ្តុំនៃធាតុ ដែលមានប្រភេទទិន្នន័យដូចគ្នា ដែលត្រូវបានរក្សាទុកតំលៃនៅ កន្លែងផ្សេងគ្នា រៀងគ្នាជាជួរដូចទៅនឹង Array ដែរ។ ធាតុនីមួយៗរបស់ ត្រូវបាន Access តាមរយៈ Index ។

List បែងចែកជា ២ ប្រភេទ ៖
- Fixed Length List
- Growable List

**២.១. Fixed-length list**

គឺជាប្រភេទ List ដែលយើងបង្កើតឡើង ដោយកំណត់ចំនួនធាតុជាក់លាក់ឲ្យវា។ ហើយយើងមិនអាចកែប្រែ បន្ថែម ឬ លុប ធាតុវាបានឡើយនៅពេល Run-time ។

ទម្រង់ទូទៅរបស់ Fixed-length list

```dart
List<data_type> list_name = List<data_type>.filled( SizeOfList, default_value );
```

- data_type គឺជាប្រភេទទិន្នន័យគោលរបស់ List គឺសំដៅលើប្រភេទទិន្នន័យរបស់ ធាតុនីមួយៗដូចជា int double String...ជាដើម។
- list_name សំដៅទៅលើការកំណត់ឈ្មោះរបស់ List
- SizeOfList: គឺជាតម្លៃថេរជាចំនួនគត់ ដែលមានតម្លៃចាប់ពី 0 ដល់ n ដែលប្រើ សំរាប់កំណត់ចំនួនធាតុរបស់ List។
- default_value គឺជាតម្លៃ Default សម្រាប់ធាតុនីមួយៗនៅក្នុង List ។

**ឧទាហរណ៍**

```dart
void main() {
   List<int> myList = List<int>.filled(3, 0);
   print( myList );
}
```

**២.២. Growable List**

គឺជាប្រភេទ List ដែលយើងបង្កើតឡើង ដោយមិនចាំបាច់កំណត់ចំនួនធាតុជាក់លាក់ឡើយ។ ហើយយើងអាចកែប្រែ បន្ថែម ឬ លុប ធាតុវាបានឡើយនៅពេល Run-time បាន។

ទម្រង់ទូទៅរបស់ Growable List

```dart
List<data_type> list_name = [];
```

**ឧទាហរណ៍**

```dart
void main() {
   List<int> myList = [ 1, 2, 3, 4, 5 ];
   print( myList );
}
```

**List Properties In Dart :**

- `first` : ប្រើសម្រាប់ស្វែងរកធាតុដំបូង របស់ List
- `last` : ប្រើសម្រាប់ស្វែងរកធាតុចុងក្រោយ របស់ List
- `isEmpty` : ប្រើសម្រាប់ ពិនិត្យមើលថាតើ List គឺទទេរ
- `isNotEmpty` : ប្រើសម្រាប់ ពិនិត្យមើលថាតើ List គឺមាន
- `length` : ប្រើសម្រាប់ពិនិត្យមើលចំនួនធាតុសរុបក្នុង List
- `reverse` : ប្រើសម្រាប់ត្រឡប់ចំនួនធាតុ នៅក្នុង List
- `single` : ប្រើសម្រាប់ ពិនិត្យមើល List មានចំនួនធាតុតែមួយ

**Methods of List :**

- `add( )` : ប្រើសម្រាប់បន្ថែមចំនួនធាតុ ១ ចូលទៅក្នុង List
- `addAll( )` : ប្រើសម្រាប់បន្ថែមសំណុំធាតុ ចូលទៅក្នុង List
- `insert( )` : ប្រើសម្រាប់បន្ថែមចំនួនធាតុ ១ ចូលទៅក្នុង List នៅ index ណាមួយ
- `insertAll( )` : ប្រើសម្រាប់បន្ថែមសំណុំធាតុ ចូលទៅក្នុង List នៅ index ណាមួយ
- `remove( )` : ប្រើសម្រាប់លុបចំនួនធាតុ ១ ចេញពី List
- `removeAt( )` : ប្រើសម្រាប់លុបចំនួនធាតុ ១ ចេញពី List តាមរយៈ index
- `removeLast( )` : ប្រើសម្រាប់លុបធាតុ ចុងក្រោយរបស់ List

**៣. Set**

Set គឺជាបណ្តុំនៃធាតុ ដែលមានប្រភេទទិន្នន័យដូចគ្នា ដែលត្រូវបានរក្សាទុកតំលៃនៅ កន្លែងផ្សេងគ្នា រៀងគ្នាដូច List ដែរ ប៉ុន្តែធាតុនីមួយៗមិនស្ទួនគ្នាទេ។

ទម្រង់ទូទៅរបស់ Set

```dart
Set<data_type> set_name = {};
```

- data_type គឺជាប្រភេទទិន្នន័យគោលរបស់ Set គឺសំដៅលើប្រភេទទិន្នន័យរបស់ ធាតុនីមួយៗដូចជា int double String...ជាដើម។
- set_name សំដៅទៅលើការកំណត់ឈ្មោះរបស់ Set

**ឧទាហរណ៍**

```dart
void main() {
   Set<int> mySet = { 1, 2, 3, 4, 5 };
   print( mySet );
}
```

**៤. Map**

Map គឺជា collection មួយប្រភេទ ដែលរក្សាទុកទិន្នន័យជា គូរ Key -> Value ។ Key របស់ Map មិនអាចស្ទួនទេ(unique) តែ Value អាចស្ទួនបាន។

ទម្រង់ទូទៅរបស់ Map

```dart
Map<data_type, data_type> map_name = { key1 : value1 , key2 : value2 };
```

- data_type គឺជាប្រភេទទិន្នន័យគោលរបស់ Map គឺសំដៅលើប្រភេទទិន្នន័យរបស់ ធាតុនីមួយៗដូចជា int double String...ជាដើម។
- map_name សំដៅទៅលើការកំណត់ឈ្មោះរបស់ Map ។

**ឧទាហរណ៍**

```dart
void main() {
   Map<String, String> myMap = { "key1": "Value1" };
   print( myMap["key1"] ); // Result : Value1
}
```
